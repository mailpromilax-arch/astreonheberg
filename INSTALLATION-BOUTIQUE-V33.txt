ASTREON — REFONTE BOUTIQUE V33

Ce pack modifie uniquement :
- StoreController
- page Boutique
- nouvelle page de catégorie
- menu public
- section Gaming de l'accueil
- routes publiques de boutique

Il ne modifie pas :
- le panier
- le checkout
- Stripe
- PayPal
- le portefeuille
- les commandes
- le provisionnement Pterodactyl
- les produits ou plans en base de données

NOUVELLE STRUCTURE

INSTALLATION

Décompresser dans :
C:\Astreon\astreonheberg

Puis :

cd C:\Astreon\astreonheberg
php install-astreon-store-universes-v33.php
composer dump-autoload
npm run build
php artisan serve

Dans un autre terminal :

cd C:\Astreon\astreonheberg
npm run dev

Faire ensuite Ctrl + F5.
