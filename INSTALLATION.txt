ASTREON — À PROPOS + ÉTAT DES SERVICES V32

Installation :
1. Décompresser dans C:\Astreon\astreonheberg
2. Exécuter :

cd C:\Astreon\astreonheberg
php install-astreon-about-status-v32.php
composer dump-autoload
npm run build
php artisan serve

Dans un autre PowerShell :
cd C:\Astreon\astreonheberg
npm run dev

Puis Ctrl + F5.

Pages :
http://127.0.0.1:8000/a-propos
http://127.0.0.1:8000/status

Le menu « Autres » pointe déjà vers /a-propos et /status.
